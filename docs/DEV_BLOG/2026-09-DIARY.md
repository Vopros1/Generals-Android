# Development Diary - September 2026

---

## 2026-09-27: Android DXVK build fix

The Android APK workflow failed while configuring DXVK because the pinned
DXVK fork already includes the Android patch and has subsequent edits. The
previous reverse patch check treated that state as unpatched, then the forward
patch failed. CMake now checks the six required Android features before
attempting the patch. Older unpatched fork revisions still use the patch path.

## 2026-09-27: Android landscape orientation and game resolution

Constrained SDL3 to LandscapeLeft and LandscapeRight before video initialization,
matching the Android activity's landscape setting. The Zero Hour launcher already
normalizes a reported portrait display mode to landscape and passes the detected
size to the game's `-xres`/`-yres` arguments. It now falls back to SDL display
bounds when the current mode is unavailable, and logs a warning if neither query
provides a usable size. Explicit resolution arguments still take precedence.
